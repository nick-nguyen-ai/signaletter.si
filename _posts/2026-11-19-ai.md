  - id: silentguard
    headline: 'SilentGuard: the harness, not the model, should catch APIs that fail silently'
    takeaway: Invariant checks cut wrong answers on target faults from 74.0% to 1.7% across seven open models.
    tags:
    - Agent reliability
    - Tool calling
    - Guardrails
    sources:
    - arXiv
    - HF Papers
    verdict: Worth reading
    what_changed: This paper (submitted 16 Nov) looks at APIs that ignore part of a request, such as a misnamed filter, yet return HTTP 200 and a plausible wrong result. The authors found silent failures in 11 of 15 public research APIs, with counts inflated up to 691 times. Checklists, reviewer models and LLM judges left over 70% of answers wrong. SilentGuard tests each tool result in the harness against invariants any correct API must satisfy and withholds values that break one.
