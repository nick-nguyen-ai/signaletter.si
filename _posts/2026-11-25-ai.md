    headline: 'OpenAI and Cisco open-source Shirudo: agent-written kernel ''shields'' block exploits until a patch lands'
    takeaway: Shields are eBPF programs, signed and TPM-attested, and go live only after an operator approves.
    tags:
    - Security
    - Agents
    - Open source
    sources:
    - OpenAI blog
    - Cisco newsroom
    - X
    verdict: Worth reading
    what_changed: Shirudo (announced 23 Nov, US time) is an open-source runtime (BSD 2-Clause; BPF programs dual BSD/GPL) built on eBPF, a Linux feature that runs small checked programs inside the kernel. Agents investigate a vulnerability, write a targeted shield, and test that it blocks the exploit while legitimate requests still pass. Shields are cryptographically signed and verified before loading, and a TPM (Trusted Platform Module) keeps a verifiable record of what was loaded or removed. In OpenAI's controlled test, a Codex-generated shield blocked a Java4Shell exploit against a running Elasticsearch service without a restart.
    why_it_matters: A concrete pattern for letting agents act on production systems only under signed, operator-approved and auditable controls.
    caveats: Vendor-run tests only; Linux only; the project is early and invites contributors. Agents write the shields but people approve deployment.
