    headline: Microsoft's TokenEconomizer cuts coding-agent cost by 18–31% in its own tests
    takeaway: An open-source plugin for Claude Code, Codex, Copilot CLI and Pi that learns repo facts, prunes unused tools and redirects failure loops.
    tags:
    - Cost
    - Claude Code
    - Codex
    sources:
    - GitHub
    - arXiv
    - MarkTechPost
    verdict: Worth trying
    what_changed: 'Microsoft published TokenEconomizer v0.1.0 (Apache-2.0) on 27 Oct AEDT, with a paper by researchers from UC Berkeley, Microsoft Research and Microsoft Security; the repo has about 3,800 GitHub stars. It has three switchable parts: micro-skills that state a repo fact at the start of each session once three sessions have confirmed it (off by default), tool pruning that leaves out tools unused for 10 prompts across 2 sessions (or 5 sessions), and a loop guard whose judge sends one redirect when it is at least 70% sure a turn is stuck. It never stops a turn itself. On 277 SWE-Bench tasks, mean cost fell 18.4–30.9% across 5 agent and model pairs and was lower in all 30 repository cells. Pass@1 rose in 4 of 5 pairs, for example Copilot CLI with Sonnet 5 (−18.4% cost, +2.6 points) and Codex with GPT-5.6 Sol (−26.1%, +1.6). Claude Code with Opus 4.8 was the exception (−30.9% cost, −1.0 point).'
    why_it_matters: Cost per task is one of the numbers a bank pilot gets asked about. This is a drop-in way to measure how much of your agent spend goes to rediscovering the repo and to stuck loops.
    caveats: Results are the authors' own. Its model calls run through your agent and plan, and what it learns is stored locally in `~/.tokeneconomizer`, so review that folder before using it on sensitive code. opencode support is experimental. The release is from last week; MarkTechPost covered it on 30 Oct.
    how_to_try: Clone github.com/microsoft/TokenEconomizer, then run `claude plugin marketplace add "$PWD/TokenEconomizer"` and `claude plugin install tokeneconomizer@tokeneconomizer`. Start `claude` in a test repo, trust the folder and run `/tokeneconomizer:status`.
