    headline: A tampered Claude Code extension sat in Cursor's extension marketplace for about 11 hours and tried to plant an SSH backdoor
    takeaway: Versions 2.1.312 and 2.1.313 were malicious; Cursor says update to 2.1.314 and check your SSH keys.
    tags:
    - Cursor
    - Supply chain
    - Security
    sources:
    - Cursor blog
    - X
    verdict: Worth reading
    what_changed: Cursor says a maliciously modified Anthropic.claude-code extension (versions 2.1.312 and 2.1.313) was served from its VS Code extension marketplace from about 8:27pm Thu to 7:35am Fri AEDT (2:27am to 1:35pm PT on 29 Oct). Cursor said on X it affected at most 5,000 users, and the notice covers installs on macOS and Windows. The code added an attacker key labelled `svc-telemetry` to `~/.ssh/authorized_keys`, tried to open a reverse SSH tunnel, set up persistence (a LaunchAgent on macOS, a scheduled task on Windows) and sent host details. Cursor says turning on SSH needs admin rights, so that step failed on most machines, and the attacker's server is offline. It shut the marketplace, rotated keys and rebuilt it.
    why_it_matters: 'This is the agent supply-chain risk your bank cares about, hitting a coding-agent extension: a trusted extension name, auto-updated, with your developer''s file and network access. Worth checking any Cursor installs at work and raising extension pinning and allow-lists.'
    caveats: Figures and the impact limits are Cursor's own. Cursor says uninstalling the extension alone may not remove everything; use its remediation scripts.
    how_to_try: On macOS run `grep -qs svc-telemetry ~/.ssh/authorized_keys && echo FOUND`. If found, or if you had 2.1.312 or 2.1.313 installed, run Cursor's remediation script from the notice, then update the extension to 2.1.314.
